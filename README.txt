PALENGKE PH — FAVORITES + BULK QUANTITY PATCH

Files:
- index.html
- style.css
- script.js

Fixes:
1. Favorites now open a real list modal instead of only showing a toast.
2. Use the heart button on each product card to save/remove favorites.
3. The favorites modal can add an item to the cart or remove it from favorites.
4. Product cards include a quantity field so buyers can add many units at once (for example, 200 pineapples).
5. Cart quantities are editable using a number field, as well as +/- buttons.
6. Per product option quantity limit is 9,999 in this frontend demo.

Favorites and cart are stored in this browser's localStorage. They are not synced across devices/accounts. Inventory and real order processing still require a backend.

To test:
- Keep the three files in the same folder.
- Open index.html in a browser.
- Tap the heart on any product, then open Market Finds > Favorites.
- Enter 200 in a product's Qty field and press + to add 200 to cart.
- Open My Cart and edit the quantity directly.
